# 9702 Physics AI

An AI-powered revision tool for Cambridge International A-Level Physics (9702).

## Overview

This project helps students practise relevant exam questions by matching past-paper questions with syllabus learning outcomes.

## Features

- Organises Physics past-paper questions for revision.
- Uses semantic similarity to identify relationships between exam questions and syllabus learning outcomes.
- Combines embedding-based retrieval with BM25 keyword matching.
- Supports more targeted and efficient exam preparation.

## Technologies

- Python
- Qwen3-Embedding-0.6B
- Cosine similarity
- BM25

## How It Works

Questions and syllabus learning outcomes are converted into vector embeddings. Cosine similarity measures semantic relationships, while BM25 identifies keyword-based matches. These methods help connect exam questions with relevant syllabus content.

## Purpose

Built to make A-Level Physics revision more organised and accessible for students.
